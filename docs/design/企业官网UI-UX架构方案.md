# 通用型现代企业官网 · UI/UX 架构方案

> 版本 v1.0 ｜ 风格定位：现代 · 简约 · 时尚 ｜ 含高级动效体系
> 本文为设计规范说明，不含实现代码。视觉稿与前端实现均从本文派生。

---

## 0. 设计定位与总体原则

### 0.1 三条底层原则

| 原则 | 含义 | 反面案例（禁止） |
|---|---|---|
| **内容即秩序** | 版面秩序由内容重要性决定，不由装饰决定。所有网格、留白、动效节奏都必须服从阅读顺序 | 为了"丰富"而在首屏塞入三个并列卡片 |
| **克制的高级感** | 高级感来自精确的比例、克制的色量、干净的留白，而非特效堆砌 | 大面积渐变 + 多层投影 + 粒子背景 |
| **动效即叙事** | 动效的唯一目的是解释"从哪来、到哪去、层级如何变化" | 元素飞入、旋转、弹跳表演 |

### 0.2 视觉基调

- **气质关键词**：精密、克制、可信赖、有呼吸感
- **参照系**：瑞士国际主义排版秩序 + 现代 SaaS 控制台的信息密度 + 少量时尚媒体杂志的留白张力
- **明确排除**：霓虹色、玻璃拟态、拟物阴影、手绘插画、旋转文字、3D 元素

## 1. 全站信息架构与页面层级

### 1.1 一级导航（主导航）

固定 6 项 + 1 个转化按钮，横向排布，禁止换行、禁止超过 7 项。

| 序 | 导航标签 | 落地页 | 二级下拉 | 类型 |
|---|---|---|---|---|
| 1 | 首页 | `/` | 无 | 品牌入口 |
| 2 | 核心业务 | `/products`、`/services` | 产品中心、解决方案入口 | 浏览 + 转化 |
| 3 | 解决方案 | `/solutions` | 行业方案、场景方案 | 转化 |
| 4 | 新闻动态 | `/news` | 企业动态、行业资讯 | 浏览 |
| 5 | 关于我们 | `/about` | 企业简介、荣誉资质、发展历程 | 品牌 |
| 6 | 联系我们 | `/contact` | 无 | 转化 |
| — | 咨询 CTA | 跳转 `/contact#form` | — | 转化按钮 |

**导航规则**

- 首屏导航透明浮于内容之上，滚动超过 80px 后转为实底 + 底部细分割线（高度从 88px 收拢至 64px）
- 二级下拉仅在「核心业务」「解决方案」「新闻动态」三项出现，面板宽度不超过 320px，最多 2 列
- 导航右侧固定「咨询合作」主按钮，任何页面可见
- 移动端：右上角汉堡 → 全屏抽屉（导航项纵向排布，底部固定 CTA）

### 1.2 页脚（四栏 + 订阅条）

```
┌──────────────────────────────────────────────────────────┐
│  订阅条：输入邮箱 → 订阅按钮（通栏，浅色底）              │
├────────────┬────────────┬────────────┬───────────────────┤
│ 品牌区      │ 核心业务   │ 解决方案   │ 联系我们           │
│ Logo       │ 产品中心   │ 行业方案   │ 地址（占位）      │
│ 一句话定位  │ 服务中心   │ 场景方案   │ 电话 / 邮箱       │
│ 备案号      │            │            │ 社交媒体图标组     │
├────────────┴────────────┴────────────┴───────────────────┤
│ 版权信息 · 法律声明 · 隐私政策 · 站点地图        返回顶部  │
└──────────────────────────────────────────────────────────┘
```

- 桌面端四栏平铺，移动端折叠为手风琴（默认全部收起）
- 返回顶部按钮：滚动超过 600px 后从右侧滑入

### 1.3 各页面模块清单

#### 首页（品牌 + 转化双重职责）

| # | 模块 | 内容组织 | 动效编排 |
|---|---|---|---|
| 1 | 顶部导航 | — | 初始透明，滚动变实底 |

**内容组织逻辑**：首屏 → 凭什么信你（指标）→ 你提供什么（业务）→ 怎么解决（方案）→ 别人怎么说（客户）→ 最近在做什么（新闻）→ 行动（CTA）。严格对应"认知 → 信任 → 兴趣 → 决策"的漏斗。

#### 核心业务（产品中心 / 服务中心）

```
列表页                                    详情页
├ 页面头（标题 + 简介 + 面包屑）            ├ 面包屑
├ 分类筛选栏（吸顶）                        ├ 标题 + 摘要 + 元信息
│  ├ 分类 Tab                               ├ 主视觉图 / 图集
│  ├ 能力筛选（多选标签）                    ├ 核心卖点 3–4 宫格
│  └ 排序 + 视图切换（卡片/列表）            ├ 详细图文（分节，带锚点目录）
├ 结果计数 + 已选条件（可清除）              ├ 规格参数表
├ 卡片网格（3 列）                          ├ 关联方案 / 关联产品
└ 分页（加载更多）                           └ 底部转化区块 + 同类推荐
```

- 产品与服务**共用一套列表/详情模板**，仅通过 `type` 字段区分文案与配色徽标，保证复用性
- 服务详情额外含"服务流程"横向步骤条（4 步）

#### 解决方案

```
总览页：Hero → 按行业分类的方案矩阵 → 场景标签筛选 → 定制 CTA
详情页：Hero（行业/痛点背景）→ 客户挑战 → 解决方案架构图 → 
        实施路径 4 阶段 → 成果数据 → 关联产品 → 关联案例 → 咨询 CTA
```

#### 新闻动态

| 类型 | 列表页 | 详情页 |
|---|---|---|
| 企业动态 | 头条大图 + 下方 2 列 | 标题 + 日期 + 正文（宽度 720px 居中，左侧吸顶目录） |
| 行业资讯 | 3 列卡片 + 标签归档侧栏 | 同上，正文上方可有引言块/引用块 |

- 归档：按年份 + 标签双维度，支持标签交叉筛选
- 详情页底部：上一篇 / 下一篇 + 相关阅读 3 条

#### 关于我们

三个纵向叙事段落在同一页面内以锚点串联，或拆为三个子页（推荐拆页，便于独立投放与 SEO）：

1. **企业简介**：定位陈述 → 数据概览 → 企业理念 → 企业环境图集
2. **荣誉资质**：分类筛选（资质证书 / 行业奖项 / 体系认证）→ 证书墙 → 可点击查看大图
3. **发展历程**：横向/纵向时间轴，按阶段分组（初创 / 成长 / 领先 / 生态）

#### 联系我们

- 分渠道联系信息卡片（销售 / 客服 / 合作 / 媒体），每张含专属邮箱与电话占位
- 咨询表单：姓名 / 公司 / 邮箱 / 电话 / 咨询类型（下拉）/ 留言 / 隐私同意
- 地图嵌入 + 「获取路线」外链
- FAQ 折叠面板（4–6 条）
- 总部与分公司地址列表

## 2. 设计系统规范

### 2.1 配色方案

采用 **中性主调 + 单一品牌强调色 + 低饱和功能色**。原则：色量控制——单屏内品牌色占比不超过 15%，强调色只用于"引导下一步"的位置。

#### 品牌主色（占位，可替换）

| Token | 值 | 用途 |
|---|---|---|
| `--color-primary` | `#1A56DB` | 主按钮、链接、选中态、关键强调 |
| `--color-primary-hover` | `#1544B0` | 悬停 |
| `--color-primary-subtle` | `#EEF3FE` | 选中背景、标签底色 |
| `--color-accent` | `#FF6B35` | 极少量的引导色，仅用于"限时/新品/重点"徽标 |

> 若企业无既定品牌色，建议以深蓝或深墨绿为主色（可信赖），避免高饱和红黄。

#### 中性色阶

| Token | 值 | 用途 |
|---|---|---|
| `--color-ink-900` | `#0B0F19` | 主标题 |
| `--color-ink-700` | `#1F2937` | 正文标题 |
| `--color-ink-500` | `#4B5563` | 正文 |
| `--color-ink-400` | `#6B7280` | 辅助文字 |
| `--color-border` | `#E5E7EB` | 分割线、边框 |
| `--color-surface` | `#F7F8FA` | 浅色区块底 |
| `--color-bg` | `#FFFFFF` | 页面底 |

#### 功能色（低饱和处理，避免喧宾夺主）

| Token | 值 | 用途 |
|---|---|---|
| `--color-success` | `#12805C` | 表单成功、状态正常 |
| `--color-warning` | `#B45309` | 警告 |
| `--color-danger` | `#DC2626` | 错误、必填校验失败 |
| `--color-info` | `#0E7490` | 提示 |

#### 深色区块（首页转化段、页脚、Hero 备选方案）

底色 `#0B0F19`，文字 `#FFFFFF` / 次级 `#9CA3AF`，品牌色在深底上提亮至 `#5B8DEF` 以保证对比度 ≥ 4.5:1。

#### 对比度红线

- 正文与背景 ≥ 4.5:1
- 大字号（≥24px）标题 ≥ 3:1
- 交互元素边界与相邻色 ≥ 3:1
- 禁用：纯红配纯绿、纯蓝配纯黄、蓝底黄字

### 2.2 字体层级

**字体族**

- 中文：思源黑体 / Noto Sans SC / 系统无衬线回退
- 西文与数字：Inter（数字启用等宽数字 `font-variant-numeric: tabular-nums`，防止跳动）
- 衬线变体（可选，用于引言、荣誉标题）：Noto Serif SC

**字阶（桌面端）**

| 层级 | 字号 / 行高 | 字重 | 字距 | 用途 |
|---|---|---|---|---|
| Display | 64 / 1.1 | 600 | -0.02em | 首屏主标题 |
| H1 | 48 / 1.2 | 600 | -0.02em | 页面主标题 |
| H2 | 36 / 1.3 | 600 | -0.01em | 区块标题 |
| H3 | 26 / 1.4 | 600 | 0 | 卡片主标题 |
| H4 | 20 / 1.5 | 600 | 0 | 小节标题 |
| Body-L | 18 / 1.7 | 400 | 0 | 导语、列表引文 |
| Body | 16 / 1.75 | 400 | 0 | 正文 |
| Caption | 14 / 1.6 | 400 | 0 | 图注、辅助 |
| Micro | 12 / 1.5 | 500 | 0.02em | 标签、徽标 |
| Button | 16 / 1 | 600 | 0 | 按钮文字 |

**移动端字阶**：Display 降至 36，H1 降至 32，H2 降至 26，H3 降至 20，其余不变。行高全局上浮 0.05。

**规则**

- 中文正文单行不超过 34 字（约 680px），详情页正文栏宽固定 720px
- 每屏至多两级字号对比，避免多层级并存
- 禁用斜体（中文无真斜体）、禁用文字阴影、禁用纯黑 `#000`

### 2.3 间距与栅格

**间距刻度（4px 基线）**：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 / 128 / 160`（单位 px）

**栅格**

| 断点 | 容器宽度 | 列数 | 槽宽 | 边距 |
|---|---|---|---|---|
| ≥1440 | 1280（可 1320） | 12 | 24 | 32 |
| 1200–1439 | 1140 | 12 | 24 | 32 |
| 992–1199 | 960 | 12 | 24 | 24 |
| 768–991 | 720 | 8 | 20 | 24 |
| <768 | 100% 流式 | 4 | 16 | 20 |

**纵向节奏**：区块垂直内边距桌面 96–128px，平板 72px，移动 56px。相邻区块间距不得小于 96px（桌面）。

**对齐**：所有内容左对齐于容器栅格，禁止居中超过 680px 的文本块；仅首屏标题、引言、CTA 区块可居中。

### 2.4 圆角与阴影

| Token | 值 | 用途 |
|---|---|---|
| `--radius-sm` | 6px | 标签、输入框、小图标容器 |
| `--radius-md` | 10px | 按钮、卡片 |
| `--radius-lg` | 16px | 大卡片、图片框、弹窗 |
| `--radius-xl` | 24px | 首屏图形容器、模态 |
| `--radius-full` | 999px | 头像、胶囊标签 |

**阴影（两级即可，禁止多层叠加）**

| Token | 值 | 用途 |
|---|---|---|
| `--shadow-sm` | `0 1px 2px rgba(11,15,25,.06), 0 1px 3px rgba(11,15,25,.04)` | 静态卡片 |
| `--shadow-md` | `0 8px 24px rgba(11,15,25,.10), 0 2px 6px rgba(11,15,25,.04)` | 悬浮态、下拉、吸顶导航 |
| `--shadow-lg` | `0 24px 60px rgba(11,15,25,.16)` | 模态、移动端抽屉 |

### 2.5 图标风格

- **风格**：线性（stroke 1.5px，圆角端点），统一 24×24 网格，符号在 20px 视区内居中
- **来源**：单一线性图标库，禁止混用不同风格
- **尺寸**：16 / 20 / 24 / 32 / 40 五档
- **状态**：默认 `--color-ink-400`，悬停 `--color-primary`，禁用 40% 不透明度
- **配文字规则**：图标仅在语义明确时单独使用（关闭、搜索、箭头、外部链接）；删除、警告类图标必须配文字
- **配图规则**：产品与场景类内容必须用真实图位或 AI 生成图占位，禁止用图标代替真实内容图

### 2.6 通用组件规范

#### 按钮

| 变体 | 背景 | 文字 | 边框 | 用途 |
|---|---|---|---|---|
| Primary | `--color-primary` | 白 | 无 | 页面主要 CTA，每屏至多 1 个 |
| Secondary | 白 | `--color-primary` | 1px primary | 次要行动 |
| Ghost | 透明 | `--color-ink-700` | 无 | 三级行动、卡片内链接 |
| Dark | `--color-ink-900` | 白 | 无 | 深色区块内 CTA |
| Link | 透明 | primary | 下划线动画 | 文字链接式行动 |

- 尺寸：高 大 56 / 中 48 / 小 40；左右内边距 24（大）/ 20（中）/ 16（小）
- 圆角 `--radius-md`，图标在左或右（箭头类在右，间距 8）
- 悬停：背景加深 + 整体 `translateY(-2px)` + 阴影升级，200ms
- 按下：`translateY(0)` + 缩放 0.98，100ms
- 加载中：文字替换为旋转指示器，按钮宽度不变，禁止高度跳变
- 禁用：40% 不透明度 + `cursor: not-allowed`，保留可读性
- 焦点态：2px primary 外框 + 2px 间距，仅键盘可见

#### 卡片

- 结构：图区（可选，比例 16:9 或 4:3）→ 内容区（标签 + 标题 + 摘要 ≤ 2 行 + 链接）
- 内边距 24（桌面）/ 20（移动）
- 默认静态 `--shadow-sm` + `--radius-lg`
- 悬停：`translateY(-4px)` + `--shadow-md` + 图片 `scale(1.04)`，300ms
- 整卡可点击时必须有明确 hover 态与"整卡链接"语义（`cursor: pointer` + 焦点可见）
- 卡片之间间距：网格 24px，列表 16px

#### 表单

- 布局：桌面两列（宽字段占满整行），移动单列；标签始终在输入框上方
- 输入框：高 48px，圆角 `--radius-sm`，边框 1px `--color-border`
- 聚焦：边框转 primary + 2px 浅色外环，200ms
- 校验：失焦时校验，错误态边框 danger + 下方 12px 错误文案（带图标），不用红色抖动
- 必填：标签后加 `*`，并在提交按钮上方统一说明
- 下拉/日期/单选：统一 48px 高，右侧 16px 箭头图标
- 复选框：单个 20×20；需勾选隐私同意的复选框文字必须可点击
- 提交按钮：表单区右下或通栏（移动端通栏），加载态禁用并显示进度
- 成功反馈：原地替换表单为成功态（图标 + 文本 + 「继续浏览」链接），不弹窗

#### 其他必备组件

| 组件 | 规范 |
|---|---|
| 标签 / 徽标 | 高 24，圆角 full，12px 字重 500；分类色 3 种以内 |
| 面包屑 | 12–14px，当前页不可点，层级 ≤ 3，首页可省略 |
| 分页 | 桌面显示页码 + 前后箭头，移动端用「加载更多」 |
| 模态 | 遮罩 60% 黑 + 背景模糊 4px；宽度 480/640/960 三档；ESC 与遮罩点击可关闭 |
| 抽屉 | 右侧 480px，移动端全屏；打开时主体不滚动 |
| 抽屉式筛选（移动端） | 底部弹起高度 85vh，底部固定「查看 N 项结果」按钮 |
| 空状态 | 图标 + 一句话说明 + 一个行动按钮 |
| 404 | 简洁插画占位 + 返回首页 + 搜索框 |
| 提示条 Toast | 顶部居中，停留 3s，成功/错误/信息三态 |

## 3. 关键页 UX 流程与交互

### 3.1 首屏叙事（首页 / 页面头）

**结构顺序**：Eyebrow（小标签）→ 主标题（价值主张，不含公司名）→ 副标题（一句话说明能做什么）→ 双 CTA（主 + 次）→ 主视觉 → 信任指标条

**标题写法约束**：不超过 14 字，必须包含"客户能获得的结果"，不使用"创新/领先/赋能"等空词。

**滚动叙事编排**

1. 首屏加载：主视觉 `scale .96→1` + `opacity 0→1`（800ms），标题分行错峰上浮（每行延迟 80ms）
2. 向下滚动：主视觉以 `translateY` 反向位移形成轻微视差（位移量 ≤ 60px）
3. 信任指标条进入视口：数字从 0 滚动到目标值（1200ms，`easeOutExpo`）
4. 第二屏起：每个区块进入视口时 `opacity 0→1` + `translateY 24→0`（600ms），同屏多个元素交错延迟 80ms

### 3.2 产品 / 服务列表

**筛选交互**

- 分类 Tab：横向排列，切换时下方内容做淡出→淡入（150ms 淡出 + 300ms 淡入），不做横向滑动
- 能力筛选：多选标签，选中后结果计数即时更新（`正在筛选 3 项`）
- 排序：下拉选择，切换后结果区淡出淡入
- 视图切换：卡片 / 列表，切换时布局交叉淡入（250ms）
- 已选条件：显示为可删除的胶囊标签，支持一键清除
- 筛选状态写入 URL query，保证分享与返回可复原

**分页与滚动**

- 使用「加载更多」按钮而非无限滚动：原因——SEO 可索引、页脚可达、用户有明确终点感
- 点击后追加内容，新条目逐个淡入

**卡片进入视口**：淡入 + 上浮 16px，网格内按索引交错 60ms

**详情页**

- 页面头（面包屑 + 标题 + 摘要 + 元信息）后接主视觉图
- 长文详情提供左侧吸顶目录（滚动高亮当前章节，IntersectionObserver）
- 底部固定转化条：桌面端在滚动至页尾时从底部滑入（产品名 + 「咨询该产品」）；移动端常驻底部安全区上方
- 相关内容：同分类最多 3 条，不足则放宽到同行业

### 3.3 解决方案筛选

**筛选器设计（横向筛选条，不做侧栏）**

1. 第一层：**行业**（单选 Tab，6–8 项，如 制造业 / 金融 / 零售 / 医疗 / 教育 / 政务）
2. 第二层：**能力场景**（多选标签，如 数字化转型 / 降本增效 / 风险管控 / 数据治理）
3. 第三层：**规模**（单选：大型 / 中型 / 小微，可省略）

**交互**

- 任一筛选变更 → 结果区淡出 150ms → 重新布局淡入 300ms，卡片交错入场 50ms
- 无结果时：显示空状态 + 「清除筛选」按钮 + 推荐全量方案
- 结果计数实时更新
- 筛选状态同步 URL

**方案详情页强调路径**

`客户挑战 → 方案架构 → 实施路径 → 成果数据 → 咨询`
其中「实施路径 4 阶段」用横向步骤条，桌面端横向、移动端纵向时间轴，滚动时当前阶段高亮。

### 3.4 新闻列表与详情

**列表**

- 企业动态：头条（16:9 大图 + 标题 + 摘要 + 日期）占满一行，下方 2 列次条
- 行业资讯：3 列卡片，附标签与日期
- 归档侧栏（桌面）：年份列表 + 热门标签，选中后列表淡入刷新；移动端收进顶部下拉
- 翻页：页码分页，切换时列表淡出淡入并滚动到列表顶部

**详情**

- 顶部：面包屑 → 分类标签 → 标题（≤ 32 字）→ 发布日期 / 作者 / 阅读量（元信息用 13px 辅助色）
- 首图：宽度 1200，居中，圆角 16
- 正文：栏宽 720px，行高 1.8，段落间距 24px
  - 元素规范：小标题 H3、二级标题 H4、引用块左侧 3px primary 边 + 斜体衬线、表格横向可滚动、代码/数据用等宽
- 左侧吸顶目录（宽度 ≥ 1200px 时出现）：列出 H2/H3，滚动高亮
- 阅读进度条：页面顶部 2px primary 进度条
- 分享：右侧浮动组（复制链接 / 分享到社交），滚动出现
- 底部：标签云 + 上一篇/下一篇 + 相关阅读 3 条 + 订阅条
- 移动端：目录收进顶部「本文目录」折叠面板

### 3.5 发展历程时间轴

**结构**：按阶段分组（初创期 / 成长期 / 领先期 / 生态期），每阶段含年份区间、阶段主题、2–4 条事件

**布局**

- 桌面：左侧固定年份轴（垂直线 + 节点），右侧内容区；滚动时轴线随进度填充（primary 色从上往下生长）
- 移动：垂直单轴，节点在左，内容在右，轴线同样滚动填充
- 荣誉资质节点：用方形节点区分，普通事件用圆形节点

**交互**

- 节点进入视口：节点缩放 0.6→1 + 内容淡入上浮，200ms
- 点击节点：对应年份内容滚动至视口中部（800ms `easeInOutCubic`）
- 悬停节点：显示 Tooltip（年份 + 事件标题）
- 「展开全部 / 收起」控制：默认显示每阶段前 2 条，点击展开其余，展开时高度过渡 400ms

### 3.6 联系表单与地图

**表单交互流程**

1. 字段失焦 → 单字段校验（必填、邮箱格式、手机格式、长度）
2. 输入时实时清除该字段的错误态
3. 点击提交 → 全表单校验，滚动到第一个错误字段并聚焦
4. 提交中 → 按钮加载态、字段禁用
5. 成功 → 表单原地替换为成功态：勾选图标 + 「我们已收到您的咨询，将在 1 个工作日内联系您」+ 「提交另一条咨询」链接
6. 失败 → 顶部错误提示条 + 保留已填内容，不清空

**地图**

- 桌面端：右侧 sticky 地图（占 40% 宽，随左侧表单滚动固定），下方地址 + 「获取路线」外链
- 移动端：地图置于表单之后，高度 320px，点击进入全屏
- 地图默认使用静态图占位，点击加载真实地图（避免首屏第三方脚本拖慢）
- 地图容器圆角 16，加 `--shadow-sm`
- 多地址：公司总部 / 分公司 Tab 切换，切换时标记点做缩放脉冲动画

**FAQ 折叠面板**：手风琴，同一时间最多展开 1 项，展开高度过渡 300ms，图标旋转 180°。

## 4. 动效设计方案

### 4.1 动效原则

1. **动效服务于空间关系**：用户看完动效应该更清楚"这块从哪来、那块去哪了"
2. **动效时长上限**：入场 ≤ 800ms，悬停 ≤ 300ms，页面转场 ≤ 500ms，超过 800ms 的动画会显得迟钝
3. **只动 transform 和 opacity**：避免动 `width/height/top/left`，避免触发重排
4. **距离递减**：元素离视口越近入场越快；已进入视口的元素不再重复播放
5. **同类元素同步**：一组同类元素应同时开始（或极短交错），避免视觉噪音

### 4.2 缓动曲线

| Token | 曲线 | 用途 |
|---|---|---|
| `--ease-out` | `cubic-bezier(0.16, 1, 0.3, 1)` | 入场（默认首选，收尾快 feels 灵敏） |
| `--ease-in-out` | `cubic-bezier(0.65, 0, 0.35, 1)` | 页面转场、双向状态切换 |
| `--ease-out-soft` | `cubic-bezier(0.25, 0.46, 0.45, 0.94)` | 大位移视差 |
| `--ease-spring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 仅用于徽标、小图标反馈（弹性 ≤ 10%） |
| `--linear` | `linear` | 进度条、无限循环指示器 |

禁止使用 `ease-in`（起步慢，用于入场会显得迟钝）、禁止 `linear` 用于任何状态切换、禁止弹跳超过 10% 的回弹曲线。

### 4.3 滚动入场（Scroll Reveal）

| 元素类型 | 位移 | 时长 | 缓动 | 交错 |
|---|---|---|---|---|
| 区块标题 | `translateY 24px → 0` | 600ms | `--ease-out` | 0 |
| 卡片网格 | `translateY 32px → 0` + 淡入 | 600ms | `--ease-out` | 每列 80ms |
| 图片 | `opacity 0→1` + `scale .98→1` | 700ms | `--ease-out` | 0 |
| 文字块 | `translateY 16px → 0` | 500ms | `--ease-out` | 60ms |
| 分割线 | `scaleX 0→1`（左端为原点） | 500ms | `--ease-out` | 0 |
| 首屏标题分行 | `translateY 40px → 0` + 淡入 | 800ms | `--ease-out` | 每行 80ms |

**触发规则**：IntersectionObserver，`threshold 0.15`（元素 15% 可见即触发），`rootMargin 0px 0px -10%`（略微提前）。触发后立即 `unobserve`，只播一次。

**降级**：IntersectionObserver 不可用时 → 所有元素直接置为终态（可见），绝不允许因动效失败而"内容不可见"。

### 4.4 视差（Parallax）

| 场景 | 层速 | 位移上限 | 缓动 |
|---|---|---|---|
| 首屏主视觉背景 | 0.85× | 60px | `--ease-out-soft` |
| 深色转化区背景图形 | 0.9× | 40px | `--ease-out-soft` |
| 方案交替图文（桌面） | 0.95× | 30px | linear（跟随滚动） |
| 解决方案页 Hero | 0.8× | 80px | `--ease-out-soft` |

**实现约束**：
- 用 `transform: translate3d()`，`will-change: transform` 仅在动画进行时添加
- 每帧更新，写入 `requestAnimationFrame` 节流
- **桌面端（≥992px）才启用**；平板与移动端一律关闭
- 同一视口内最多 3 个视差层

### 4.5 悬浮微交互

| 触发 | 效果 | 时长 | 缓动 |
|---|---|---|---|
| 卡片悬停 | `translateY -4px` + 阴影 sm→md | 300ms | `--ease-out` |
| 卡片图片 | `scale 1 → 1.04` | 500ms | `--ease-out` |
| 按钮悬停 | `translateY -2px` + 背景加深 | 200ms | `--ease-out` |
| 图标按钮悬停 | 背景浅色圆 + `scale 1.06` | 200ms | `--ease-out` |
| 文字链接悬停 | 下划线 `scaleX 0→1`（左原点）+ 颜色转 primary | 250ms | `--ease-out` |
| 导航下拉 | 面板 `opacity + translateY -8px + scaleY .96` | 220ms | `--ease-out` |
| Logo 墙项 | 灰度 → 彩色 + `opacity` 提升 | 400ms | `--ease-out` |
| 表单聚焦 | 边框换色 + 外环 `scale .96→1` | 200ms | `--ease-out` |
| 筛选标签切换 | 背景色切换 + `scale .92→1` | 240ms | `--ease-spring` |
| 输入框聚焦/失焦 | 边框与外环透明度 | 200ms | `--ease-out` |

### 4.6 页面转场

| 场景 | 效果 | 时长 | 缓动 |
|---|---|---|---|
| 站内路由切换 | 旧页 `opacity 1→0` + `translateY 0→-12px`；新页 `opacity 0→1` + `translateY 16px→0` | 离场 150ms / 入场 400ms | `--ease-in-out` / `--ease-out` |
| 内容区局部刷新（筛选/分页） | 仅结果区淡出淡入，不做位移 | 150 / 300ms | `--ease-out` |
| 移动端抽屉 | 从右侧滑入 `translateX 100%→0`，遮罩淡入 | 300ms | `--ease-out` |
| 模态 | 遮罩淡入 + 面板 `scale .96→1` 淡入 | 250ms | `--ease-out` |
| 返回顶部 | 滚动行为由浏览器接管（平滑） | — | — |

**关键约束**：转场**不做整页横向滑动**（企业站横向滑动易被误认为页面已结束）。整页转场总时长控制在 550ms 内。

### 4.7 无障碍与降级处理

**必须遵守（硬性）**

1. 尊重 `prefers-reduced-motion: reduce`
2. 该设置下：所有滚动入场、视差、页面转场、循环动画**全部关闭**，元素直接呈现终态
3. 保留必要的状态反馈（表单校验、筛选结果、加载态），但改为淡入淡出且时长 ≤ 150ms
4. 数字滚动改为直接显示最终数值
5. 悬停微交互保留（它是即时反馈而非运动），但移除位移，仅保留颜色/阴影变化

**性能降级（按序触发）**

| 条件 | 降级动作 |
|---|---|
| `navigator.connection.saveData === true` | 关闭视差与图片入场缩放，图片全部静态占位 |
| 设备内存 ≤ 4GB 或 `hardwareConcurrency ≤ 4` | 关闭视差，滚动入场改为纯淡入（无位移） |
| 页面滚动 FPS < 50 | 全局关闭视差与 `scale` 类动画，仅保留 `opacity` |
| 首屏 JS 体积超预算 | 动效库改为按需加载，动效作为增强而非阻塞 |

**其他无障碍要求**

- 所有动效元素不得导致闪烁（每秒闪烁 ≤ 3 次）
- 焦点态必须可见，且不被动效遮挡
- 视差与入场不得延迟可交互时间（TTI 不因动效延长）
- 提供"关闭动画"的用户手动开关（在页脚或 Cookie 设置中），优先级高于系统设置
- 文字与背景对比度达标的约束在第 2.1 节已规定，动效不得引入半透明叠加导致对比度下降
- 尊重 `prefers-contrast: more` 时，加深边框与文字色

- 横向滚动的图集需提供可见的滚动指示器
- 固定底部元素需预留 `env(safe-area-inset-bottom)`

## 6. 性能与 SEO 基础要求

### 6.1 性能预算

| 指标 | 目标 |
|---|---|
| LCP | ≤ 2.5s（移动端 75 分位） |
| INP | ≤ 200ms |
| CLS | ≤ 0.1 |
| 首屏关键 CSS | ≤ 60KB（未压缩） |
| 首屏 JS | ≤ 200KB（未压缩，含框架与动效库） |
| 单页图片总量 | ≤ 1.5MB（首屏 ≤ 800KB） |
| 字体 | ≤ 3 个字重，中文子集化，按需异步加载 |

**关键措施**

1. 图片：首屏主视觉使用 AVIF/WebP + `srcset` 响应式尺寸 + 显式宽高防 CLS；非首屏图片 `loading="lazy"` + `decoding="async"`
2. 首屏主图 `fetchpriority="high"`，其余 `fetchpriority="low"`
3. 动效相关代码按需加载，动效不可阻塞首屏渲染
4. 字体使用 `font-display: swap` + 中文子集化，避免 FOUT 白屏
5. 视差与滚动监听使用被动监听（passive）+ rAF 节流，避免阻塞滚动
6. 只运行视差/滚动动画的可见视口内元素，离开视口停止
7. 第三方脚本（地图、视频、统计）全部延后加载，地图点击后才初始化
8. 静态页面 HTML 直出，不依赖客户端渲染首屏内容

### 6.2 SEO 基础

**URL 与层级**

- URL 全小写、连字符分隔、无参数污染（如 `/solutions/retail-industry`）
- 层级不超过 3 层，每层有独立可索引页面
- 规范链接：列表页筛选参数不生成独立索引页，统一 `canonical` 指向无参数地址
- 分页页从第 2 页起加 `rel="canonical"` 指向第 1 页，或使用 `rel="prev/next"`（与主流搜索引擎策略保持一致）

**结构化数据**

| 页面 | Schema 类型 | 关键字段 |
|---|---|---|
| 首页 | Organization + WebSite | 名称、Logo、地址、电话、`potentialAction` 搜索 |
| 产品/服务详情 | Product / Service | 名称、描述、图片、所属企业 |
| 新闻详情 | NewsArticle / BlogPosting | 标题、发布日期、作者、图片、publisher |
| 解决方案 | Article | 标题、所属行业 |
| FAQ | FAQPage | 问题与答案（用于富结果） |
| 企业与荣誉 | Organization + Award | 荣誉名称、颁发方、时间 |

**页面级要素**

- 每页唯一 `<title>`，结构为「核心关键词 - 次级关键词 - 品牌名」，≤ 60 字符
- 每页唯一 meta description，≤ 150 字符，包含核心关键词与价值点
- 规范的 `<h1>` 每页仅一个，层级不跳级（h1 → h2 → h3）
- 所有图片有 `alt`，装饰性图片 `alt=""`
- 语义化标签：`header / nav / main / article / section / footer`
- 面包屑同步输出 BreadcrumbList 结构化数据
- 内链策略：产品↔方案双向链接、新闻正文内链到相关产品与方案、页脚快捷入口

**内容与体验类**

- 新闻详情标注发布日期与更新时间，页面可见
- 提供 `sitemap.xml`、`robots.txt`、RSS 订阅
- 长文提供目录锚点，利于抓取与跳转
- 无 JavaScript 时核心内容（导航、正文、联系方式）仍可访问
- 移动端友好，单列自适应，文本无需横向滚动
- 页面无侵入式弹窗、无强制跳转，避免影响移动端排名

**安全与可信度**

- 全站 HTTPS
- 明确的隐私政策与法律声明页
- 企业真实信息占位需标注：`XX科技有限公司` / `地址占位` / `ICP备案号占位`
