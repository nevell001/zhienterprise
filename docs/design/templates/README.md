# 企业官网 · 5 套行业模板使用说明

## 文件结构

```
templates/
├─ base.css          共用组件基座（导航/按钮/卡片/表单/动效/页脚/响应式）
├─ themes.css        5 套主题变量（唯一差异层）
├─ rv.js             动效基座（滚动入场/校验/手风琴/筛选/进度条/目录）
├─ index.html        首页 · 带模板切换器，可当场对比五套
├─ about.html        关于我们 · 企业简介
├─ honor.html        关于我们 · 荣誉资质
├─ history.html      关于我们 · 发展历程
├─ news-list.html    新闻动态 · 列表（二三级菜单）
├─ news-detail.html  新闻动态 · 详情
└─ contact.html      联系我们（表单 + 地图 + FAQ）
```

## 一、架构：两层分离

```
base.css   ← 组件层。所有模板共用。改这里，五套同时变
themes.css ← 变量层。每套模板只写 :root 变量
```

**这就是可复用性的核心。** 如果你在 base.css 里给某个按钮改了圆角，五套模板的所有按钮都会变——不需要改五遍。

## 二、5 套模板的差异表

| 模板 | class | 主色 | 圆角 | 字体 | 母题 |
|---|---|---|---|---|---|
| 管理咨询 | `t-consult` | `#185FA5` 深蓝 | 4/6/8/12 偏小 | Noto Sans + **衬线标题** | 指针罗盘 · 方向与决断 |
| 信息技术 | `t-tech` | `#0F6E56` 墨绿 | 6/10/16/24 | Noto Sans | 节点连接 · 架构与连接 |
| 制造业 | `t-mfg` | `#B0442A` 赭红 | 3/5/6/8 **硬朗** | Noto Sans，**标题带竖线** | 模块榫接 · 结构与咬合 |
| 商贸 | `t-trade` | `#7C4A9E` 紫 | 8/12/20/28 偏大 | Noto Sans | 流通曲线 · 连接与流转 |
| 数码产品 | `t-digital` | `#C2410C` 暖橙 | 10/14/22/32 **最大** | Noto Sans，阴影最轻 | 产品轮廓 · 实体与细节 |

### 圆角是最容易被忽视的行业信号

- 制造业 `3px` 圆角 + 3px 竖线标题 = 硬、准、工业
- 数码产品 `32px` 圆角 + 轻阴影 = 软、亲和、消费电子
- 同样一句"我们的产品"，配 3px 圆角和 32px 圆角，气质完全不同

如果客户说"我们想要科技感但不要太冷"，改圆角比改颜色更有效。

## 三、切换模板

**方式 1（推荐，先验证）**：打开 `index.html`，点顶部切换器。

**方式 2（交付时）**：改 `index.html` 的 `<html class="t-consult">` 为目标模板，并把切换器 div 删掉。

```html
<!-- 单模板交付：删掉这段 -->
<div class="switcher">...</div>
```

## 四、新增一套模板的步骤

1. 在 `themes.css` 里加一个 `.t-xxx{...}`，只写变量
2. 在 `index.html` 的 `MOTIFS` 里加一套 SVG 母题
3. 在 `index.html` 的 `CONF` 里加文案配置
4. 在 `ART` 里加方案卡插画

**不需要动 base.css 一行。**

## 六、动效实现说明

`rv.js` 内含五个模块，全部符合方案文档 §4.7 的降级要求：

| 模块 | 行为 | 降级 |
|---|---|---|
| 滚动入场 | IntersectionObserver 阈值 0.15，触发后 unobserve | 不支持时全部直接置终态 |
| 表单校验 | 失焦校验 + 输入时清除错误 | 无动画依赖 |
| 手风琴 | 高度过渡 300ms | reduce 时过渡 0.01ms |
| 筛选 | 显示/隐藏 + 计数更新 | 无动画依赖 |
| 进度条 / 目录 | 滚动监听（passive） | 无动画依赖 |

**关键：`IntersectionObserver` 不可用时，元素直接加 `.in` 显示终态，绝不会因为动效失败导致内容不可见。** 这是 §4.7 里唯一不可妥协的红线。

## 七、已知取舍

1. **切换器是演示工具，交付前必须删除。**
2. **地图是 SVG 占位。** 生产环境应替换为静态图 + 点击加载真实地图（§6.1 性能预算：第三方脚本延后加载）。
3. **表单无后端。** 当前为前端校验 + 成功态演示，接入时替换提交逻辑。
4. **新闻列表筛选基于 `data-cat` 属性**，未接 URL query。接入时按 §3.2 补 URL 同步。
5. **图片全部为 SVG 占位。** 生产环境按 §6.1 图片规范替换（AVIF/WebP + srcset + 显式宽高）。
